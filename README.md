# Magolla Farm Financial Dashboard

A mobile-first financial management dashboard for farm operations.

## Features

- Real-time financial tracking (revenue, expenses, profit)
- Cash flow management across multiple accounts
- Visual analytics with charts and trends
- Customer payment tracking
- Inventory management with alerts
- M-Pesa and local bank integration

## Tech Stack

- React 18 + TypeScript
- Vite
- Zustand
- Tailwind CSS
- Recharts
- Supabase

## Getting Started

```bash
# Clone repository
git clone https://github.com/YOUR-USERNAME/magolla-farm-dashboard.git
cd magolla-farm-dashboard

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env

# Start development server
npm run dev
```

## Branch Workflow

- `dev` - Active development
- `staging` - Testing
- `cloudflare-live` - Production (protected)

## Deployment

This project deploys to Cloudflare Pages automatically when changes are merged to `cloudflare-live`.
